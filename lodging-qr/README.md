# 숙박자 정보 입력 (QR)

숙소에 QR 코드를 붙이면 숙박자가 휴대폰으로 정보를 입력하고 손가락으로 서명합니다. 관리자는 `/admin`에서 명부를 확인하고 CSV로 내려받습니다.

## 입주자 카드 자동 생성
- 제출이 들어오면 카드 번호(예: `20261126-001`)를 붙여 `data/cards/<기록ID>.html`로 자동 저장합니다.
- 관리자 표의 '카드 보기'에서 같은 카드를 열고 인쇄할 수 있습니다.
- 보관 기간이 지나 기록이 삭제되면 카드 파일도 함께 삭제됩니다.

## 수집 항목
- 필수: 성명, 연락처, 주소, 입실일·퇴실일, 방문목적, 서명, 개인정보 동의
- 선택: 차량번호, 성별, 생년월일, 국적, 여권번호(외국인), 동반인 이름

## 실행

```bash
ADMIN_TOKEN=원하는비밀번호 PORT=3000 RETENTION_DAYS=365 node server.js
```

- 입력 화면: `http://서버주소:3000/`
- 관리자 화면: `http://서버주소:3000/admin?token=원하는비밀번호`
- `RETENTION_DAYS`: 보관 기간(일). 지난 기록은 새 제출 시 자동 삭제됩니다. 기본 365일이며 실제 기간은 법령을 확인해 정하세요.
- 외부 패키지 없이 Node.js 22 이상에서 동작합니다.

## 주의

- 제출 데이터와 서명 이미지는 `data/guests.jsonl`에 저장되며 Git에서 제외되어 있습니다.
- HTTPS 뒤에서 운영하세요(리버스 프록시 권장). 평문 HTTP로 개인정보를 받으면 안 됩니다.
- 항목·보관 기간은 공중위생관리법 및 시행규칙, 개인정보 보호법을 확인해 맞춰 주세요. 이 코드는 법적 요건을 검증하지 않았습니다.
- 관리자 토큰은 URL에 들어가므로 공용 PC나 공유 링크에 남기지 마세요.
