# 숙박자 정보 입력 (QR)

숙소에 QR 코드를 붙이면 숙박자가 휴대폰으로 정보를 입력하고, 관리자는 `/admin`에서 명부를 확인·CSV로 내려받습니다.

## 실행

```bash
ADMIN_TOKEN=원하는비밀번호 PORT=3000 node server.js
```

- 입력 화면: `http://서버주소:3000/`
- 관리자 화면: `http://서버주소:3000/admin?token=원하는비밀번호`
- 외부 패키지 없이 Node.js 22 이상에서 동작합니다.

## 주의

- 제출 데이터는 `data/guests.jsonl`에 저장되며 Git에 올라가지 않도록 제외되어 있습니다.
- 서버는 HTTPS 뒤에서 운영하세요(리버스 프록시 권장). 평문 HTTP로 개인정보를 받으면 안 됩니다.
- 보관 기간·제출 항목은 관련 법령(공중위생관리법 및 시행규칙, 개인정보 보호법)을 확인해 맞춰 주세요. 이 코드의 항목은 일반적인 예시이며 법적 요건을 검증한 것이 아닙니다.
- 관리자 토큰은 URL에 들어가므로, 공용 PC나 공유 링크에 남기지 마세요.
